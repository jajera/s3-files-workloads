Provision the S3 bucket, file system, mount targets, IAM roles, and security groups — plus the compute resource — in a single `terraform apply` using the [terraform-aws-s3-files](https://github.com/jajera/terraform-aws-s3-files) modules. These pages replace the manual CLI walkthroughs for EC2, ECS, and Lambda.

<Aside type="note">
  The examples require **Terraform >= 1.5** and the **AWS provider >= 6.40**. AWS credentials must be configured before running `terraform apply`.
</Aside>
