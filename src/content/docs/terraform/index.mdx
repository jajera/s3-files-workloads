Provision the S3 bucket, file system, mount targets, IAM roles, and security groups — plus the compute resource — in a single `terraform apply` using the [terraform-aws-s3-files](https://github.com/jajera/terraform-aws-s3-files) modules. These pages complement the CLI walkthroughs for EC2 and Lambda, and add ECS Fargate and ECS on EC2 examples that are Terraform-only.

<Aside type="note">
  The examples require **Terraform >= 1.5** and the **AWS provider >= 6.40** (use **>= 6.41** for the ECS Fargate and ECS on EC2 examples, which use native `s3files_volume_configuration`). AWS credentials must be configured before running `terraform apply`.
</Aside>
