Mount an S3 file system inside an **AWS Lambda function** by attaching an access point and configuring `file-system-configs`. Lambda **requires an access point** — it cannot mount a file system by ID alone.

Complete [Setup](/s3-files-workloads/lambda/setup/bucket/) before starting here. The Lambda compute role (`s3files-compute-role-lambda`) must exist from [IAM](/s3-files-workloads/lambda/setup/iam/).

<Aside type="caution">
  The Lambda function must run in the same VPC as the S3 Files mount targets, and the subnet must have a route to the mount targets on port 2049 TCP.
</Aside>
